Install PalanuOS on a board

For a board with nothing on it, or to start over. A running PalanuOS updates itself from Remote > Device instead (its data is kept). This writes the bootloader, the partition table and the system over USB with Web Serial (Chrome or Edge on a computer).

  1. Plug the board in with a USB cable.
  2. Press Connect and pick its serial port. If none shows, hold the board's BOOT button while you plug it in.
  3. Press Install. It takes a minute or two; the board restarts into PalanuOS.
